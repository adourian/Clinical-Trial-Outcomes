# Data Folder

The required datasets are too large to host directly in this repository.

To download them, follow the instructions below:

1. Visit: [https://huggingface.co/datasets/kariad/clinical_trial_data](kariad/clinical_trial_data)
2. Download the `data.zip` file.
3. Extract and place the contents in this `/data` folder.

Ensure the structure matches this:
data/
├── compiled_clinical_trials_data.csv
├── embedded_dataset.csv.csv
├── raw_data.csv
└── read_xml.py
